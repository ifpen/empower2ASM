# ASM schemas

`liquid-chromatography.tabular.embed.schema.json` is the Allotrope Foundation's REC/2026/09 liquid chromatography schema, with every referenced schema embedded, copied unchanged from `json-schemas/adm/liquid-chromatography/REC/2026/09/` in the [ASM repository](https://gitlab.com/allotrope-public/asm). It is used only by the tests, to check that mapped ASM Documents are valid.
